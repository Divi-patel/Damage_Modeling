## Boundary

These notebooks explain the damage layer for hurricane wind: hazard intensity to damage ratio, then an illustrative
conditional loss when an explicit value basis is supplied. Event frequency, site hit probability, EAL, PML, VaR and
TVaR remain in the Hazard modeling tier.
