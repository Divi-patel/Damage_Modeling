# flood notebooks

Notebook companions for flood damage-curve cells.

## Cells

| Asset | Notebook folder | Current purpose |
|---|---|---|
| Solar PV | [`solar/`](solar/) | Curation walkthrough and runtime walkthrough for the canonical `flood_solar` curve artifact. |
| Real estate | [`real_estate/`](real_estate/) | Curation walkthrough and runtime walkthrough for the noncanonical `flood_real_estate` proposal (model v0.2). |

## Boundary

These notebooks explain the damage layer for flood: local flood intensity at each component datum to
failure-unit damage ratio, then optional conditional loss assembly when explicit value/exposure inputs are
supplied. Flood hazard frequency, site inundation probability, EAL, PML, VaR, and TVaR remain downstream.
