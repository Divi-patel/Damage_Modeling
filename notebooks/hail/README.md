# hail notebooks

Notebook companions for hail damage-curve cells.

## Cells

| Asset | Notebook folder | Current purpose |
|---|---|---|
| Solar PV | [`solar/`](solar/) | Curation walkthrough and runtime walkthrough for the canonical `hail_solar` curve artifact. |
| Real estate | [`real_estate/`](real_estate/) | Curation walkthrough and runtime walkthrough for the noncanonical `hail_real_estate` proposal (model v0.1). |

## Boundary

These notebooks explain the damage layer for hail: hail intensity to damage ratio, then optional conditional
loss assembly when an explicit value basis is supplied. Hail event frequency, site hit probability, EAL, PML,
VaR, and TVaR remain in the Hazard modeling tier.
