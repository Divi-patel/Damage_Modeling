## Validation and done when

The immediate checkpoint is done when a reproducible numerical/value review and readable comparison exist;
that checkpoint passed. The **plan is not done** until a qualified response and scoped capability are
handed to Hazard and the diagnostic consumer proof passes. Every unsupported unit/event remains explicit.
A new release must resolve the reference helper's stale proposal metadata and qualify the actual consumer,
rather than treating this review helper as installed production code.

Annual capability may only expand through its governed gates. Deterministic DR is compatible with a
stochastic annual hazard calculation, but that fact does not satisfy the frequency, spatial, value,
coverage, cap or compound-event evidence requirements. Avoid presenting a truncated 0–10 ft annual
calculation as complete if the hazard process has probability mass outside the curve domain.
