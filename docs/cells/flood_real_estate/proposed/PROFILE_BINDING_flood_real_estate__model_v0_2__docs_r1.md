# Profile binding — flood_real_estate model v0.2 / docs r1

Binds the model-v0.2 records to the **Hazard reference profiles r1** (source FRE-S013), the three buildings the
real-estate CONUS grid will place at every cell. The cell keeps its own selector IDs; this note and the
[binding table](PROFILE_BINDING_flood_real_estate__model_v0_2__docs_r1.csv) say which record serves which profile, how
well it fits, and what the consumer must do. Decisions D-FRE-26 (binding), D-FRE-27 (office), D-FRE-28 (coastal).

## 2. Profile fields and whether they change the flood curve

| Profile field | House | Warehouse | Office | Effect on flood curve selection |
|---|---|---|---|---|
| Occupancy | single-family | warehouse storage | office | **Selects the record** (RES1 / COM2 / COM4) |
| Stories | 1 | 1 | 3 | **Selects** for RES1; COM2 and COM4 defaults do not vary by height (office bias recorded) |
| Basement / foundation | none / slab | none / slab | none / slab | **Selects** (no-basement defaults) |
| First-floor height above grade | 0.75 ft | 0.25 ft | 0.25 ft | **Shifts the depth** (§4); same as the cell's reference values |
| Structure | wood frame | pre-engineered steel | braced steel, composite floors | Not a Hazus key |
| Age / condition | 20 years | 20 years | 20 years | Not a key |
| Floor area | 1,800 ft² | 100,000 ft² | 54,000 ft² | Not a key; enters dollars only |
| Equipment heights, elevator pit | panel, air handler 0.5 ft | switchboard 0.5 ft, heaters 20 ft | controls 0.5 ft, 4 ft pit, rooftop HVAC | **Not used**: whole-building curves do not read equipment heights |
| Roof, walls, openings, doors | — | — | — | No effect on still-water curves (wind and hail only) |
| Flood protection | none | none | none | Consistent: protection must already be in the delivered depth |

**No missing profile detail changes the flood curve selection.** Two profile facts matter and are already declared:
first-floor height (§4) and the office's three storeys (recorded as a known bias of the FEMA default).

## 3. Contract for the consumer

| Item | Rule |
|---|---|
| Demand | Water depth in ft above the first floor, `flood_depth_above_first_floor_ft`: the source-native axis and the field the common v3 loader reads. Hazard converts from grade once (with the profile's first-floor height) and it is never shifted again. The reference evaluator also accepts `flood_depth_above_grade_ft` and converts itself. Never send both |
| Dry ground | Depth above grade ≤ 0 returns 0 (D-FRE-24). **With floor-relative depth, Hazard applies this rule itself** (the curve cannot tell a dry building from water just below the floor): DF 129 reads 3% at −1 ft and 13% at the floor, so a dry house would otherwise show about 5%. The reference evaluator applies it in the above-grade mode |
| Domain | ft above the floor: Hazus records −4 to 24. Below: 0. Above: withheld (`ABOVE_SOURCE_VALID_RANGE`) |
| Conditioner | `flood_water_type` (event state, owned by Hazard) is required; freshwater and coastal surge give the **same record** for the three profiles; unknown withholds (`FLOOD_WATER_TYPE_UNKNOWN`) |
| Routing | By `reference_building_id` (and `band`); for the three profiles each building has exactly one record, so the common v3 loader's selector-only routing is unambiguous |
| Output | Failure-unit damage ratio of `FRE_BUILDING_STRUCTURE`, conditional on the event; no frequency, annual loss or downtime |
| Uncertainty | Point value only for the three profiles; no sampleable spread. NACCS bounds remain only on the unbound retail coastal record |

## 5. Value mapping

| Item | Content |
|---|---|
| Source denominator | Structure value of the same building: Hazus structure replacement value (FRE-C001) |
| Requested groups covered | Foundation/floor, frame, roof, walls/openings, fixed services and interiors, **as one source-native assembly** |
| Excluded | Contents, land, site works, business interruption, process equipment (same as the profiles) |
| Covered fraction of the profile budget | **Not stated by the source.** Hazus does not list the components inside "structure"; the fraction is not set to 1.0 here. Applying the ratio to the full budget ($405,000 house, $11.0M warehouse, $10.8M office) is the natural screening reading, but it is Hazard's value-qualification call |
| Office | The ratio is of whole-building value; it is not allocated by floor area (the height effect is in the curve's recorded bias, not in the value) |
| Overlap | Single assembly: no component response may be added for the same pathway and event |
| Price basis | The ratio is unitless; the profile budgets (RLB Q3 2025 Dallas) do not change it |
