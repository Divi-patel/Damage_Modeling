# Profile binding — flood_real_estate model v0.1 / docs r1

Binds the proposed curve records to the **Hazard reference profiles r1** (source FRE-S013), the three buildings the
real-estate CONUS grid will place at every cell. **No curve changes.** The cell keeps its own selector IDs
(`RE_RES_SFD_1S_SLAB`, `RE_IND_WAREHOUSE`); this note and the [binding table](PROFILE_BINDING_flood_real_estate__model_v0_1__docs_r1.csv)
say which record serves which profile, how well it fits, and what the consumer must do. Decision D-FRE-26.

defaults are class averages, and the claims check (FRE-S012) is a comparison, not a fit.

## 2. Profile fields and whether they change the flood curve

| Profile field | House | Warehouse | Effect on flood curve selection |
|---|---|---|---|
| Occupancy | single-family | warehouse storage | **Selects the record** (RES1 / COM2) |
| Stories | 1 | 1 | **Selects** for RES1 (one-storey default); COM2 default does not vary |
| Basement / foundation | none / slab | none / slab | **Selects** (no-basement defaults; NACCS slab prototypes) |
| First-floor height above grade | 0.75 ft | 0.25 ft | **Shifts the depth** (§4); same as the cell's reference values (D-FRE-22) |
| Structure | wood frame | pre-engineered steel | Not a Hazus key; matches the NACCS prototype (5A wood; 3 steel / light metal) |
| Age / condition | 20 years, serviceable | 20 years, serviceable | Not a key; inside the NACCS 5A most-likely range (15–30 years) |
| Floor area | 1,800 ft² | 100,000 ft² | Not a key; enters dollars only |
| Office fitout | — | 4,000 ft² inside the building | Not a key; inside the COM2 class average |
| Equipment heights | panel, air handler 0.5 ft | switchboard 0.5 ft, heaters 20 ft, roof HVAC | **Not used**: whole-building curves do not read equipment heights |
| Large doors, roof, walls, openings | — | 8 overhead doors, metal roof | No effect on still-water curves (wind and hail only) |
| Flood protection | none | none | Consistent: protection must already be in the delivered depth |

**No missing profile detail changes the flood curve selection for the house or the warehouse.** The one field that
moves results materially is first-floor height (§4), which the profiles already declare.

## 3. Contract for the consumer

| Item | Rule |
|---|---|
| Demand | Water depth in ft. **Preferred:** send `flood_depth_above_grade_ft`; the evaluator subtracts the reference first-floor height once. **Alternative:** send `flood_depth_above_first_floor_ft` already converted by Hazard; it is never shifted again. Never send both a converted depth and a floor height |
| Dry ground | Depth above grade ≤ 0 returns 0 (D-FRE-24). **This rule can only be applied when depth is sent above grade.** If Hazard sends floor-relative depth, Hazard must apply it itself: DF 129 reads 3% at −1 ft and 13% at the floor, so a dry house would otherwise show about 5% |
| Domain | Each record's own range, in ft above the floor: freshwater −4 to 24, coastal −1 to 10. Below: 0. Above: withheld (`ABOVE_SOURCE_VALID_RANGE`) |
| Conditioner | `flood_water_type` (event state, owned by Hazard): freshwater or coastal surge route to their records; unknown withholds (`FLOOD_WATER_TYPE_UNKNOWN`); never blended |
| Output | Failure-unit damage ratio of `FRE_BUILDING_STRUCTURE`, conditional on the event; no frequency, annual loss or downtime |
| Uncertainty | Freshwater: point value only. Coastal: point value plus NACCS Min/Max, a building-variant envelope; scenario bounds, not quantiles, not to be sampled |

## 5. Value mapping

| Item | Content |
|---|---|
| Source denominator | Structure value of the same building: Hazus structure replacement value, NACCS structure value (FRE-C001) |
| Requested groups covered | Foundation/floor, frame, roof, walls/openings, fixed services and interiors, **as one source-native assembly** |
| Excluded | Contents, land, site works, business interruption, process equipment (same as the profile) |
| Covered fraction of the profile budget | **Not stated by the source.** Neither library lists the components inside "structure"; the fraction is not set to 1.0 here. Applying the ratio to the full budget ($405,000 house, $11.0M warehouse) is the natural screening reading, but it is Hazard's value-qualification call |
| Overlap | Single assembly: no component response may be added for the same pathway and event |
| Price basis | The ratio is unitless; the profile budgets (RLB Q3 2025 Dallas) do not change it |
