# Decision log — tropical_cyclone_wind_real_estate model v0.1 / docs r1

Entries are **proposed** on 2026-10-12 for JL's decision unless marked **JL decided** (checkpoint 2, 2026-10-12).
JL's decisions are scientific choices for this proposal; the cell as a whole still needs owner review before any
canonical use.

| ID | Decision | Reason | Alternatives considered | Revisit trigger |
|---|---|---|---|---|
| D-TCRE-01 | One cell, `tropical_cyclone_wind_real_estate`, for all three asset types; the reference building is a selector on one failure unit. | Same mechanism, axis, source library and denominator across the three types. The name follows the sibling cells `tropical_cyclone_wind_solar` / `_wind`, so hurricane, typhoon and tropical storm share one address. Mirrors `flood_real_estate` D-FRE-01. | `hurricane_wind_real_estate`; three cells by type. | A type needs a different mechanism, axis or value boundary. |
| D-TCRE-02 | Reuse the three `flood_real_estate` reference buildings with identical IDs and attributes; add only wind-specific attributes (D-TCRE-07). | A building priced by both cells must be the same building, so the losses can be compared and combined. | Separate wind reference buildings. | `flood_real_estate` changes a reference building. |
| D-TCRE-03 | Axis = peak 3-second gust at 10 m, open terrain, in mph (`tc_peak_gust_3s_10m_mph`). Saffir-Simpson category and one-minute or ten-minute sustained wind are rejected as inputs. Damage applies no averaging-period, height or terrain bridge. | It is what Hazard delivers (3-s gust, 10 m, mph, Exposure C) and the native axis of the Hazus functions (confirmed: TCRE-C001). Same gust basis as `tropical_cyclone_wind_wind`; the unit is mph instead of km/h to match Hazard and Hazus without a conversion. | km/h or m/s; sustained wind with an internal gust factor (would repeat Hazard's bridge). | Step 3 finds the Hazus axis is not open-terrain 3-s gust; Hazard changes its delivered field. |
| D-TCRE-04 | One pathway, `tropical_cyclone_wind`, that **includes** the windborne-debris and rain-ingress damage embedded in the source loss functions. No separate debris or rain-ingress pathway may be added while records are Hazus-based. | Hazus simulates pressure, missile impact and water entry through breaches in one building model and publishes one loss ratio (confirmed: TCRE-C002, Hazus 7.0 TM §2.1 p. 2-4). They cannot be separated without component-level output. Adding them separately would count the same damage twice. This deliberately differs from the sibling cells, whose wind-loading-only sources exclude them. | Wind pressure only (no source separates it); separate debris and rain pathways (no source). | A source publishes separable component or mechanism losses. |
| D-TCRE-05 | Grain = one source-native whole-building record per reference building (and wind-characteristic combination). No separate roof failure unit in v0.1 unless step 3 finds a source that supports one. Roof attributes enter as selectors. | The Hazus loss function is whole-building (confirmed: TCRE-C004, C011). Doc 06 asks to split the roof "where the sources support it". Precedent: `flood_real_estate` D-FRE-03, `flood_wind` whole-substation atom. | Roof / envelope / interior split from Hazus damage-state definitions (would invent costs). | A component-level wind source is curated. |
| D-TCRE-06 | **JL decided — terrain is a required selector** `hazus_terrain_class` with the five Hazus classes (open, light_suburban, suburban, light_trees, trees). No default, no interpolation between classes; the gust stays the open-terrain gust, so terrain is applied once. Mapping a site roughness to a class is the consumer's rule. | Hazus indexes every function to the open-terrain gust and publishes one curve per terrain class (TCRE-C001, C005). Terrain moves the house about 3× at 120 mph (TCRE-C018). | Fixed suburban for every building; fixed open terrain (also not the worst case for the commercial building, TCRE-C024). | Hazard adds a roughness field and a mapping rule; FEMA documents interpolation. |
| D-TCRE-07 | **JL decided — unknown wind characteristics are fixed at their most common value** (highest all-region average in Hazus 7.0 Table C-2), each as a named field of the record. House: gable, no SWR, 6d @ 6"/12", toe-nail, no garage. Commercial: BUR, low window area, debris environment B, standard metal deck. Warehouse: old roof deck, standard metal deck. No shutters for all (reference building). | Keeps every attribute visible so a later measure is a one-field change (doc 06 §8); most common, not worst case (TCRE-C010). | Hazus typical mix (averages variants and hides the attributes). | A regional reference building or a mix is wanted. |
| D-TCRE-08 | Out of scope: storm surge, waves and rainfall flooding (→ `flood_real_estate`); TC-spawned tornadoes (→ a future convective-wind × real-estate cell); contents, loss of use, BI (deferred; Hazus publishes contents and loss-of-use functions). | Matches Hazard's sub-peril routing (surge → Flood Coastal, rainfall → Flood Pluvial) and the sibling cells' boundaries; doc 06 "building (structure) damage first". | Fold surge or contents into this cell. | Owner adds contents for real estate. |
| D-TCRE-09 | Denominator = structure replacement cost new, 100% on the one failure unit, shared with `flood_real_estate`; the per-area cost stays the shared open seam and scenario dollars stay withheld. | One building, one value basis across perils. Hazus building loss ratio is relative to total building replacement value (confirmed: TCRE-C004). | Market, assessed or depreciated value. | JL selects a per-area source (applies to both cells). |
| D-TCRE-10 | The legacy `hurricane_tropical_cyclone_wind_storm_residential` ("Climada") and `strong_wind_small_residential` arrays are not evidence for this cell. | No averaging period, height, terrain or building type; unexplained 37% saturation; the second is straight-line wind (coverage note §2). | Use as a cross-check. | — |
| D-TCRE-11 | Wind and flood losses on the same building for one storm are combined by the consumer, which must keep the total at or below 100% of structure value. This cell records the rule; it does not implement it. | Two cells, one building; Hazard has no storm identity today, so the join cannot be built yet. Same `event_family_id` rule as the sibling cells. | Cap inside each cell (cannot see the other peril). | Hazard adds storm identity for wind and surge. |
| D-TCRE-12 | Outside the selected curves' published wind range the result is withheld (no clamp, no extrapolation); below the lowest published speed, the source's own zero is used only if the source states it. | Same range policy as `flood_real_estate` and `tropical_cyclone_wind_wind`. Hazard's 61–229 mph lies inside the Hazus range (50–250 mph; refined by D-TCRE-18). | Clamp to the last value. | Step 5 fixes exact ranges. |
| D-TCRE-13 | Tree fall on the house is deferred: withheld, not zero. Hazus applies it as an additive term to small residential buildings using tree height, type and density; it is not inside the base WSF1 record. | Stated in the manual (TCRE-C003); Hazard supplies no tree data. Adding it later does not double-count the base record. | Fold a typical tree term into the house record. | Hazard supplies tree data. |
| D-TCRE-14 | **JL decided — house = Hazus WSF1 (continental US variants, CaseID 1).** | Exact match: wood frame, one story, shingle roof (TCRE-C006). | WSF2; MSF1 (masonry). | — |
| D-TCRE-15 | **JL decided — commercial = Hazus SECBL** (steel engineered commercial, 1–2 stories; numerically identical to MECBL, so masonry or steel frame give the same curve). Roof cover BUR (the most common Hazus low-slope membrane). Masonry strip mall MLRM1 is a recorded alternative profile. | Engineered low-rise commercial fits "small low-rise retail or office, masonry or steel frame" (TCRE-C007). MLRM1 loses about twice as much at 140 mph (pressure test §2). | MLRM1; single-ply membrane (SPM) roof. | Reference building redefined as strip-mall retail or 3 stories (SECBM). |
| D-TCRE-16 | **JL decided — warehouse = Hazus SPMBL** (pre-engineered metal building, > 50,000 ft²). The reference warehouse therefore carries a floor-area assumption above 50,000 ft², which the value basis must use too. The SPMB superior-deck rows are excluded and may not be offered as a measure until FEMA explains them. | Matches pre-engineered steel; doc 06's teaching warehouse is large (TCRE-C008). The rd110 rows duplicate other size classes (TCRE-C016); the selected row is clean and directionally consistent (TCRE-C017). | SPMBM (medium); MLRI (masonry warehouse). | Reference floor area set below 50,000 ft²; FEMA corrects the SPMB family. |
| D-TCRE-17 | Values between published speeds use straight lines between the published 5-mph points; every published value is kept, including the dips of at most 0.2 points above 200 mph. No smooth form is fitted. | Dense table; nothing to fill; same practice as the table-based cells (curve form §2; TCRE-C014). | Running-maximum repair; smooth fit. | A selected record dips by more than 0.005. |
| D-TCRE-18 | Below 50 mph the result is 0 (every selected record is exactly 0 at 50 mph); above 250 mph it is withheld; no clamp or extrapolation. All records share the 50–250 mph range. | Source's own zero and range (TCRE-C014); Hazard's 61–229 mph lies inside; one shared range fits the current loader (TCRE-C020). Refines D-TCRE-12. | Withhold below 50 mph. | A selected record is non-zero at 50 mph. |
| D-TCRE-19 | Wind characteristics are request fields with the reference value as the only published value: if omitted, the reference value is used and flagged; if a different value is sent, the result is withheld (`WIND_CHARACTERISTIC_VARIANT_NOT_PUBLISHED`). | Prevents a shuttered or strapped building from being priced silently as the reference; makes later measure records a pure addition. Same pattern as the first-floor-height default in `flood_real_estate`. | Reject requests that send any characteristic field. | Measure variants are published. |
| D-TCRE-20 | Ordinates come from the FEMA-provided Hazus 6.1 extract (third-party mirror), verified identical to SimCenter's independent Hazus 5.1 copy; the method is cited from the Hazus 7.0 manual. Default characteristic weights come from the 7.0 manual, not from the extract. | The manual prints no loss tables (TCRE-C011, C012, C013). | Read values off manual figures. | FEMA publishes a 7.x extract. |
| D-TCRE-21 | Package design for v0.1: records route by `reference_building_id` and `hazus_terrain_class` (both selectors); one pathway-level `valid_range` [50, 250] mph on `tc_peak_gust_3s_10m_mph`; no conditioner; point values only (no bounds). | Fits the current Hazard generic loader without record-level ranges (TCRE-C020). | Terrain as a conditioner; record-level ranges. | Consumer cutover design. |
