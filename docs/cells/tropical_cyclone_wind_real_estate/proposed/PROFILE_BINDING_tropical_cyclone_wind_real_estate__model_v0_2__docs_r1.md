# Profile binding — tropical_cyclone_wind_real_estate model v0.2 / docs r1

Binds the model-v0.2 records to the **Hazard reference profiles r1** (source TCRE-S010). The cell keeps the shared
selector IDs (same as `flood_real_estate` v0.2); this note and the
[binding table](PROFILE_BINDING_tropical_cyclone_wind_real_estate__model_v0_2__docs_r1.csv) say which records serve
which profile and how well they fit. Decisions D-TCRE-22 to D-TCRE-25.

## 1. Binding

Each bound profile has five records, one per Hazus terrain class. The retail record `RE_COM_LOWRISE` (SECBL) stays in
the package, bound to no profile.

## 2. Profile fields and whether they change the wind curve

| Profile field | Effect |
|---|---|
| Storeys | **Selects** the Hazus height class: office 3 → SECBM (not SECBL) |
| Structure | **Selects** the type: wood → WSF1; pre-engineered steel → SPMB; braced steel → SECB (masonry MECB gives the same values at the sampled speeds) |
| Floor area | **Selects** the SPMB size class: 100,000 ft² → SPMBL; no effect on the other types |
| Roof cover | **Selects**: TPO membrane → SPM for the office; shingle for the house; the metal warehouse roof is not a separate characteristic |
| Roof cover age | **Selects** the warehouse roof deck age: 10 years → new or average (FEMA: 2008 or later) |
| Window-to-wall ratio | **Selects** the office window area: 33% → medium (25–40%) |
| Opening protection | **Selects**: none → no shutters, all three |
| Roof form, garage | **Selects** for the house: gable; no garage |
| Building age (20 years) | **Not used directly.** Hazus would pick house connections from the local code for that age; one reference house is placed everywhere, so the most common values stay (D-TCRE-25) |
| Large doors (warehouse) | **Not represented**: SPMB has no door characteristic (TCRE-C028) |
| Parapet, rooftop units, wall system | Not Hazus characteristics |
| Site context | Hazard supplies the terrain class per cell (required selector) |

**One profile detail could change the house curve materially if it were known per cell:** the local building code or
design wind speed. With code-built connections (8d nails, straps) the house reads 19.0% instead of 31.3% at 120 mph in
open terrain. This is a question for the Hazard team, not a missing profile field.

## 3. Contract for the consumer

| Item | Rule |
|---|---|
| Demand | `tc_peak_gust_3s_10m_mph`: peak 3-second gust at 10 m in open terrain; Hazard converts its storm wind once; no averaging, height or terrain bridge in Damage |
| Terrain | `hazus_terrain_class` required (open, light_suburban, suburban, light_trees, trees); the consumer maps site roughness to a class; never defaulted, never applied to the gust too |
| Domain | 0–50 mph returns 0; 50–250 mph evaluates; above 250 withheld (`ABOVE_SOURCE_VALID_RANGE`); negative is an error |
| Characteristics | Optional fields; omitted → reference used and flagged; a different valid value → withheld (`WIND_CHARACTERISTIC_VARIANT_NOT_PUBLISHED`) |
| Output | Hazus building loss ratio for one storm, including wind pressure, windborne debris and rain entering through wind damage; no separate debris or rain pathway may be added |
| Combination | Wind and flood damage on one building in one storm together at most 100% of structure value (consumer) |
| Uncertainty | Point value only; variant and terrain sensitivity are stated, not sampleable |

## 5. Value mapping

Source denominator: Hazus building replacement value. Covered: foundation/floor, frame, roof, walls/openings, fixed
services and interiors as one source-native assembly; excluded: contents, land, site works, business interruption.
Covered fraction of each profile budget ($405,000, $11.0M, $10.8M): **not stated by the source**; not set to 1.0 here.
