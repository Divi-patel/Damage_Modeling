# Understand the station screening curve

One hypothetical station is placed at alternative locations. These alternatives form a
screening distribution; they are not a portfolio of stations and do not establish real
ownership or feasibility. Flood depth is measured above local station grade.

```text
water surface  ~~~~~~~~~~~~~~~~~~~~  depth above grade
station grade  ____________________  one facility reference point
               fenced station       one assembly loss ratio
```

At 2 ft the source DR is 0.04. With the selected **$27,353,236.37** fenced replacement
proxy, conditional modeled loss is **$1,094,129.45**. This is an illustrative event calculation,
not annual expected loss. The value is an engineering reference; the legacy source knots
are sourced; the exact station's damage and actual insured ownership are unknown.

Missing hazard support or a depth above the 10 ft response domain yields missing DR.
Hazard may show zero **modeled contribution** with a reason tag under the owner's screening
policy. It does not report zero physical risk. Known zero depth returns DR zero.
